# Issue #639 implementation report

## Outcome

The implementation is committed as `e751a98ec9` (`fix(gnome): render toast
titles as plain text`). Every Reprise toast now comes from one shared
constructor that disables markup before the toast is attached or configured.
The 22 former direct construction calls retain their original timeout, button,
priority, dismissal and click behavior.

No new user-visible string was added, `po/` was not regenerated, and no branch
was pushed.
