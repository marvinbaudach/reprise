# Code of Conduct

This project follows the [GNOME Code of
Conduct](https://conduct.gnome.org/).

It applies to every project space: the issue tracker, pull requests, commit
messages, and any venue where someone represents the project.

## Reporting

Report a violation to the maintainer at tomateq@pm.me. Reports are handled
confidentially. If the report concerns the maintainer, escalate to the GNOME
Foundation Code of Conduct Committee at conduct@gnome.org.

## Enforcement

The maintainer may warn, temporarily block, or permanently ban a participant
whose behaviour violates this code. Decisions are explained to the person
affected.
