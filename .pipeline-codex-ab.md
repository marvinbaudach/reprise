# Plan deviations

## Package C: exponential smoothing formula

The plan's prose formula `dt / (tau + dt)` advances exactly 50 percent when
`dt == tau`, while the required test and the term "exponential smoothing"
require approximately 63 percent after one time constant. The implementation
uses the exact frame-rate-independent exponential coefficient
`1 - exp(-dt / tau)`, which satisfies the explicit test and preserves the
specified 120 ms time constant.
